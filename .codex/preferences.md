# Codex Preferences

Предпочтения пользователя и проекта для будущих задач.

## Conversation

- Общаться с пользователем по-русски, если он не попросил иначе.
- Держать ответы живыми, короткими и по делу.
- Не останавливаться на предложении, если задача явно требует действий в файлах.

## Implementation

- Читать `AGENTS.md`, `README.md` и `docs/agent-decisions.md` перед существенными изменениями.
- Предпочитать простые локальные механизмы сложной инфраструктуре.
- Держать MVP узким.
- Не вводить запрещенные зависимости или инфраструктуру без явного решения пользователя.
- Не выдумывать unresolved details: фиксировать TODO/TBD или уточнять у пользователя, если выбор блокирует работу.

## Documentation

- Сохранять проектную документацию на английском, если файл уже написан на английском.
- Служебные Codex/agent файлы можно вести на русском с английскими техническими терминами.
- Новые фиксированные решения синхронизировать с `docs/agent-decisions.md` или `.agents/memory/decisions.md` по масштабу изменения.
